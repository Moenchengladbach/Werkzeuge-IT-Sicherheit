# Incident Response

**Incident Response (IR)** umfasst organisatorische und technische Maßnahmen zur Erkennung, Analyse, Eindämmung, Beseitigung und Nachbereitung von IT-Sicherheitsvorfällen.

## Lernziele

- Sicherheitsvorfälle strukturiert bearbeiten
- Indicators of Compromise (IOC) analysieren
- Threat Hunting verstehen
- Endpoint Detection and Response (EDR) einsetzen
- Reaktionsmaßnahmen kennenlernen

## Relevanz

Incident Response ist ein Kernbereich von Security Operations Center (SOC), Computer Emergency Response Team (CERT) und Computer Security Incident Response Team (CSIRT).
