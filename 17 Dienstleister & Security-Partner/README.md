# Dienstleister & Security-Partner

Dieser Bereich bietet eine Übersicht externer Anbieter und Spezialisten für professionelle Cybersecurity-Dienstleistungen.

## Lernziele

- Externe Unterstützungsmöglichkeiten kennenlernen
- Einsatzbereiche von Security-Dienstleistern unterscheiden
- Geeignete Spezialisten für Sicherheitsvorfälle einordnen

## Relevanz

Externe Security-Spezialisten sind insbesondere relevant, wenn Organisationen intern nicht über ausreichende Fachkenntnisse oder Ressourcen verfügen.

## Inhalt

### IT-Forensik

- [MH-Service](https://www.mh-service.de/de)
  - **Wofür:** Professionelle IT-Forensik und forensische Lösungen
  - **Relevanz:** Externe Unterstützung und professionelle Forensik

### Managed Security Operations

- [Arctic Wolf](https://arcticwolf.com/de/)
  - **Wofür:** Managed Security Operations und Security Monitoring
  - **Relevanz:** Externe Security Operations für Unternehmen
