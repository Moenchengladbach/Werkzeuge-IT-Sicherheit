# Cloud & Container Security

Cloud & Container Security umfasst Sicherheitsmaßnahmen und Werkzeuge für Cloud-Infrastrukturen, Container und moderne Plattformumgebungen.

## Lernziele

- Fehlkonfigurationen erkennen
- Container-Sicherheit kennenlernen
- Kubernetes-Sicherheit einordnen
- Identity and Access Management (IAM) in Cloud-Umgebungen verstehen

## Relevanz

Cloud- und Container-Sicherheit sind zentrale Bestandteile moderner IT-Infrastrukturen.
