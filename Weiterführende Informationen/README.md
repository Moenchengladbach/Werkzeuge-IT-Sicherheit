# Weiterführende Informationen

Dieser Bereich enthält themenübergreifende Quellen für wissenschaftliche Recherche, Statistiken und weiterführende Informationen zur IT-Sicherheit.

## Lernziele

- Wissenschaftliche Quellen recherchieren
- Fachinformationen selbstständig vertiefen
- Daten und Statistiken für Analysen finden

## Relevanz

Der Bereich ergänzt die themenspezifischen Kategorien um allgemeine Recherche- und Informationsquellen.
