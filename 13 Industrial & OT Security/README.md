# Industrial & OT Security

**Industrial Security und Operational Technology (OT) Security** beschäftigen sich mit dem Schutz industrieller Netzwerke, Steuerungssysteme und Produktionsumgebungen.

## Lernziele

- Industrielle Kommunikationsprotokolle verstehen
- Operational-Technology-(OT)-Angriffsflächen erkennen
- Unterschiede zwischen klassischer IT und OT verstehen
- Grundlagen sicherer OT-Architekturen kennenlernen

## Relevanz

OT Security ist insbesondere für Produktion, Automotive, Energieversorgung und Kritische Infrastrukturen (KRITIS) relevant.
