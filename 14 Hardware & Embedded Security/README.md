# Hardware & Embedded Security

Hardware & Embedded Security behandelt Sicherheitsanalysen von Hardware, Funktechnologien, eingebetteten Systemen und Internet-of-Things-(IoT)-Geräten.

## Lernziele

- Hardware als Angriffsfläche verstehen
- Funk- und Schnittstellentechnologien kennenlernen
- Radio Frequency Identification (RFID) und Near Field Communication (NFC) untersuchen
- Grundlagen von Embedded Security verstehen

## Relevanz

Der Bereich ist relevant für IoT, Embedded Systems, Physical Security und praktische Security-Forschung.
