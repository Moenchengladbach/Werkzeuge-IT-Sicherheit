# Schwachstellenanalyse & Security Testing

Schwachstellenanalyse und Security Testing dienen der systematischen Identifikation, Bewertung und Überprüfung von Sicherheitsproblemen in IT-Systemen und Infrastrukturen.

## Lernziele

- Schwachstellen systematisch erkennen
- Security Assessments durchführen
- Sicherheitszustände von Systemen bewerten
- Grundlagen des Penetration Testing kennenlernen

## Relevanz

Schwachstellenmanagement und Security Testing gehören zu den wichtigsten präventiven Maßnahmen der IT-Sicherheit.
