# Hardware & Embedded Security

Hardware & Embedded Security behandelt Sicherheitsanalysen von Hardware, Funktechnologien, eingebetteten Systemen und Internet-of-Things-Geräten (IoT).

## Lernziele

- Hardware als Angriffsfläche verstehen
- Funk- und Schnittstellentechnologien kennenlernen
- Radio-Frequency-Identification- und Near-Field-Communication-Technologien untersuchen
- Grundlagen von Embedded Security verstehen

## Relevanz

Der Bereich ist relevant für Internet of Things (IoT), Embedded Systems, Physical Security und praktische Security-Forschung.

## Inhalt

### Hardware- & Funkanalyse

- [Flipper Zero](https://flipper.net/)
  - **Wofür:** Untersuchung und Interaktion mit Near Field Communication (NFC), Radio-Frequency Identification (RFID), Sub-GHz-Funk, Infrarot und Hardware-Schnittstellen
  - **Relevanz:** Hardware-Security, Funktechnologien und autorisierte Security-Labs
