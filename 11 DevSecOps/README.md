# DevSecOps

**Development, Security and Operations (DevSecOps)** integriert Sicherheitsprüfungen direkt in Softwareentwicklung, Build-Prozesse und Continuous-Integration-/Continuous-Delivery-Pipelines (CI/CD).

## Lernziele

- Sicherheitsprobleme im Quellcode erkennen
- Automatisierte Security Checks verstehen
- Sicherheit in Entwicklungsprozesse integrieren

## Relevanz

DevSecOps ermöglicht die frühzeitige Erkennung von Sicherheitsproblemen während der Softwareentwicklung.
